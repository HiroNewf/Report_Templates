# Report_Templates
A collection of various cybersecurity report templates, with a focus on ones relevant to the TCM Security certification exams. 

## Exam report templates/examples
### Network Pentest report template (PNPT/PJPT)
* TCMS's: <https://github.com/hmaverickadams/TCM-Security-Sample-Pentest-Report>
* Many organizations': <https://github.com/juliocesarfort/public-pentesting-reports/>
### Webapp Pentest report templates (PWPA/PWPP)
* Erubius's: <https://github.com/Erubius/HackingHub-NahamCon-2024-Mission>
* SixSecure's: <https://github.com/Ryan-Sapone/Web-Pentest-Report>
### OSINT Investigation templates (PORP)
* TCMS's: <https://github.com/TCM-Security/osint>
* Hiro's: <https://github.com/HiroNewf/OSINT-Investigation-Report>
### Malware Analysis report templates (PMRP)

* NCSC's: https://www.ncsc.gov.uk/static-assets/documents/malware-analysis-reports/infamous-chisel/NCSC-MAR-Infamous-Chisel.pdf
* Many organizations': <https://github.com/Finch4/Malware-Analysis-Reports>
### Mobile Pentest report templates (PMPA)
